# Hackathon Management Platform

A full-stack hackathon management platform designed to streamline the participant, team, admin, and reviewer experience. Participants can securely log in, view their hackathon details, create and manage teams, and access relevant event information. The platform also provides dedicated **Admin** and **Reviewer** panels for managing participants, teams, submissions, and the evaluation process.

### Key Features

* 🔐 Participant authentication and login
* 👤 Participant profile and hackathon details
* 👥 Create and manage hackathon teams
* 🛠️ Admin panel for event and participant management
* 📝 Reviewer panel for evaluating submissions
* 📊 Centralized management of teams and participants
* 🌐 Responsive web and mobile application
* 🔄 Role-based access for Participants, Admins, and Reviewers

The platform provides a centralized system to manage the complete hackathon workflow, from participant registration and team formation to review and evaluation.
